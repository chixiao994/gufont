# 古籍字库

一个将古籍 PDF 转化为可安装 TTF 字体的 Android 应用。

从扫描/拍摄的古籍页面出发，经过校正、分列、分行、单字编辑、矢量化，最终生成一个可以装入系统的 TrueType 字体。全程在手机上完成，不需要电脑、不需要 root（除非要写入系统分区）。

---

## 核心特点

- **全流程一体化**：导入 → 校正 → 分列 → 分行 → 编辑 → 生成 → 安装，一个 App 完成
- **古籍专用**：竖排、从右往左、行距不均、双行小注、版心鱼尾，都为这些特性设计
- **纯手动几何**：校正用 4 点透视、分列用均分竖线、分行用均分横线，全部可拖，不用投影/吸附等"智能"猜测，保证精度
- **唯一编码**：每个字位有永久身份 `书名+注者+版本_p页码_c列号_r行号`，例如 `LZWBS_p003_c02_r08`（老子王弼注宋本·第3页·第2列·第8行），即使这个字不在 Unicode 里也能追溯
- **自动处理**：编辑完一个字，自动二值化 → 矢量化 → 追加到 TTF，用户无感
- **纯 Kotlin 实现**：Potrace 矢量化、TrueType 字体生成都是从零手写的，没有 native 依赖

---

## 五个步骤

| 步骤 | 功能 |
|---|---|
| ① 导入 PDF | PdfRenderer 300 DPI 转图像 |
| ② 校正 + 分列 | 4 点透视校正 + 均分竖线（右往左） |
| ③ 分割单字 | 逐列分行 + 拖动横线 + 丢弃标记 |
| ④ 编辑 | 补画/擦除 + 二值化 + 自动矢量化 + 自动入字体 |
| ⑤ 安装字体 | 预览 + 应用内安装 / 系统 root 安装 |

顶栏左上角的 ☰ 可以**直接跳到任意已完成的步骤**，不必按顺序走。

## 界面约定

**顶栏**（所有页面统一）：
```
[☰]  [文件]  [重置]  [预览]
```

- **☰**：步骤直达菜单
- **文件**：返回项目主页
- **重置**：只重置当前对象（当前页 / 当前列 / 当前字）
- **预览**：全屏只读预览

**底栏**（所有页面统一）：
```
上一张 · 跳过 · 下一张
```

语义随场景变：
- 页级 / 列级 / 字级：**下一张 = 保存当前 → 前进**
- 字体预览：三个按钮都是翻页

**通用规则**：
- 上一张 = 纯回看，不保存、不改状态、不撤销
- 跳过 = 不保存当前，直接前进
- 下一张 = 保存当前 → 前进
- 重置 = 只重置当前，不波及前后
- 改参数 = 重新均分，覆盖手动调整

## 编码规则

**字库级元信息**（写在字体文件里）：
```
书名 · 注者 · 版本
```

**字位级编码**（每个字的唯一身份）：
```
{书名缩写}{注者缩写}{版本缩写}_p{页}_c{列}_r{行}
```

示例：
- `LZWBS_p003_c02_r08` = 《老子》王弼注·宋本 · 第3页 · 第2列 · 第8行
- `LYZXS_p012_c05_r03` = 《论语》朱熹注·宋本 · 第12页 · 第5列 · 第3行

缩写规则：
- 书名/注者：拼音首字母（老子 → LZ，王弼 → WB）
- 版本：单字母（宋 S / 明 M / 元 Y / 清 Q）

**列号右往左**，第 1 列是最右列。**行号从上往下**，第 1 行是最上面的字。

## 项目文件结构

用户在 SAF 里选一个文件夹作为项目根，App 在其下创建：

```
<项目根>/
├── project.json              项目元数据、设置、进度
├── pages/
│   ├── page_001.json         页几何 + 列信息 + 状态
│   ├── page_001_src.jpg      原始页图
│   ├── page_001_corrected.png 校正后页图
│   └── ...
├── glyphs/
│   ├── glyphs.json           所有字位的索引（大表）
│   ├── LZWBS_p003_c02_r08_raw.png
│   ├── LZWBS_p003_c02_r08_edited.png
│   └── ...
└── font/
    └── output.ttf
```

全部 JSON 都是可读的、可手工修的、可 diff 的、可迁移的。备份就是把整个文件夹打包。

## 技术架构

```
┌─────────────────────────────────────────┐
│  UI 层（Compose + Material 3）           │
│  ├─ 项目列表 / 新建向导 / 项目主页        │
│  └─ 五个步骤页 + 统一顶栏底栏             │
├─────────────────────────────────────────┤
│  引擎层（纯 Kotlin，无 UI 依赖）          │
│  ├─ PDF 渲染（PdfRenderer）              │
│  ├─ 透视变换（自实现单应矩阵）            │
│  ├─ 二值化（Otsu / 固定 / 自适应）       │
│  ├─ Potrace 矢量化（边追踪 + RDP + 贝塞尔）│
│  └─ TrueType 字体生成（10 张表手写）      │
├─────────────────────────────────────────┤
│  数据层                                  │
│  ├─ 项目元数据（JSON / SAF）              │
│  └─ 字位索引（JSON / SAF）                │
└─────────────────────────────────────────┘
```

**关键技术点**：
- **透视校正**：8×8 高斯消元求单应矩阵，双线性插值采样
- **Potrace**：二值化 → 去噪 → 补洞 → 边追踪（右转优先）→ RDP 简化 → 角点检测 → 二次贝塞尔生成 → 曲线合并
- **TTF 生成**：手写 `head / hhea / hmtx / maxp / cmap / glyf / loca / name / post / OS/2` 十张表，支持 cmap format 4、glyf 坐标压缩、head 校验和
- **性能优化**：位图 LRU 缓存、协程后台处理、TTF 重建 debounce 500ms

## 构建

### 通过 GitHub Actions（推荐）

1. 把项目推送到 GitHub 仓库的 `main` 分支
2. 打开仓库的 **Actions** 页面
3. 等待 `Build APK` 工作流执行完成（约 3~5 分钟）
4. 在该次运行的 **Artifacts** 中下载 `gufont-debug`
5. 解压得到 `app-debug.apk`，传到手机上安装

也可以在 Actions 页面手动触发 `workflow_dispatch`。

### 本地构建

环境要求：
- JDK 17
- Android SDK：`platforms;android-35`、`build-tools;35.0.0`
- Gradle 8.9+

命令：

```bash
gradle assembleDebug
```

产物路径：

```
app/build/outputs/apk/debug/app-debug.apk
```

## 使用流程

### 1. 新建项目

打开 App → 点右下角「新建」→ 选择保存文件夹 → 填书名/注者/版本（可留空）→ 填编码缩写 → 创建。

### 2. 导入 PDF

进入「导入 PDF」→ 点「选择 PDF 文件」→ 自动转图像（300 DPI）→ 完成后点「下一张」进入下一步。

### 3. 校正 + 分列

- 默认显示原图 + 4 个角点，拖动角点校正，放大镜辅助
- 切到「分列」→ 显示校正后图 + 均分竖线
- 拖动竖线微调位置
- 需要丢弃某列（版心、鱼尾）：点「丢弃」→ 进标记模式 → 点列条变灰
- 底栏：上一张 / 跳过 / 下一张（下一张 = 保存当前 → 前进）

### 4. 分割单字

- 屏幕显示当前列的窄条图
- 参数栏：全局行数 / 当前列行数 / 上下重叠
- 拖动横线微调 → 每行一个字块
- 点「丢弃」→ 进标记模式 → 点行块变灰（小字、批注等可丢弃）
- 下一张 = 保存当前列 → 切出字块 → 生成字位记录 → 前进

### 5. 编辑

- 默认白笔（擦除），可切黑笔（补画）
- 笔刷大小滑块 4~64
- 二值化 Tab：Otsu / 固定 / 自适应 + 反色 + 阈值
- 顶部命名输入框：输入汉字（自动查 Unicode）或 `U+XXXX` 手动指定
- 下一张 = 保存 → 二值化 → 矢量化 → 追加 TTF → 前进
- 顶栏重置：回到默认二值 + 未涂改
- 所有字完成后 → 自动进入安装

### 6. 安装字体

- 主界面用生成的 TTF 实时渲染预览文本
- 字号滑块 + 预览文本输入框
- 点「安装字体」→ 选择「应用内安装」或「系统安装」
- **应用内安装**：仅本 App 预览用，无需 root
- **系统安装**：写入 `/system/fonts/`，需要 root，重启生效

生成的 `output.ttf` 也可以直接复制出来，装到电脑或其他设备上使用。

## 环境要求

- Android 8.0+ (API 26)
- 无需网络、无需存储权限（使用 SAF）
- 系统安装字体功能需要 root（可选）

---

## 已知限制

- 单字精裁需要手动框选，不适合全自动大批量
- 系统字体安装需要 root，普通用户只能用应用内预览
- 目前 TTF 生成的字体名固定为项目里设置的 `fontFamily`
- 一批编辑完成后手动点「重新生成」可以强制重建 TTF（自动重建有 500ms debounce）
